# EDU-MATCH
A DSA-Powered Student Skill & Service Marketplace

EduMatch is a full-stack web platform designed to help students find suitable service providers for academic, technical, and project-related requirements. Instead of manually searching through many providers, EduMatch uses Data Structures and Algorithms (DSA) to search, match, score, and rank providers according to a student's requirements.

The platform provides separate interfaces for Students, Providers, and Administrators, along with requirements, services, provider profiles, chat, orders, mock payments, reviews, reports, and dispute management.
